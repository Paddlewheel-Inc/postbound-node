# Security policy

## Reporting a vulnerability

Do not open a public issue for a security problem.

Report it privately through [GitHub private vulnerability reporting](https://github.com/Paddlewheel-Inc/postbound-node/security/advisories/new). Include the SDK version, the Node.js version, and the steps to reproduce.

We aim to acknowledge a report within 3 business days and will keep you updated until it is resolved.

## Supported versions

Only the latest published version of `postbound` receives security fixes.

## Secrets

If you find a real Postbound API key or webhook signing secret in this repository, its history, or an issue, report it the same way. Revoke any key that you control in the Postbound portal right away.
